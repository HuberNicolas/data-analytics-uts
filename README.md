# data-analytics-uts

> Workshops and notebooks from the Fundamentals of Data Analytics course at the University of Technology Sydney, covering data analysis, visualization, and foundational ML methods.

## ✨ TL;DR
```bash
poetry install && poetry shell
jupyter notebook
```

## 🚀 Features
- **Workshop notebooks:** Practical Jupyter notebooks for each course topic.
- **Data analysis pipeline:** Preprocessing, visualization, and statistical analyses.
- **Poetry environment:** Reproducible Python environment managed via Poetry.

## 🎓 Academic Context
This project was created as part of a university course.
- **Course:** Fundamentals of Data Analytics (32130), University of Technology Sydney
- **Institution:** University of Technology Sydney (UTS)
- **Semester:** Spring Semester 2024 (exchange semester)

---

## 🛠️ Installation

### Prerequisites
- Python 3.x
- [Poetry](https://python-poetry.org/)

### Steps
1. Clone the repository:
```bash
git clone https://github.com/HuberNicolas/data-analytics-uts
cd data-analytics-uts
```
2. Install dependencies:
```bash
poetry install
```

---

## 💻 Usage

```bash
poetry shell
jupyter notebook
```
